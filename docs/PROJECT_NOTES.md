# Project Notes

## Project
Weather Forecast and Alert Application

## Objective
To retrieve weather forecasts, monitor weather conditions,
and generate alerts when configured weather thresholds are reached.

## Technologies
- Python
- FastAPI
- Streamlit
- SQLite
- Pandas
- Matplotlib
- Open-Meteo API

## Main Features
1. Live weather information
2. Simulated weather data
3. Temperature forecasting
4. Rain probability monitoring
5. Weather risk alerts
6. SQLite data storage
7. CSV and JSON reports
8. Interactive dashboard

## Limitations
This is an educational project. Alerts are based on
configurable thresholds and should not replace official
weather warnings or emergency guidance.
